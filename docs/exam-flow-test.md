## 备注与结论

1. **端到端真的通了**：从建题到真实判题拿满分，整条链路（contest 编排 → auth 建号 → problem 锁版本 → submission 校验分配 → judge 真实评测 → 回写成绩）一次跑完，说明三项新功能与既有链路是自洽的。
2. **脚本里的中文会坏 JSON**：经 Git Bash 传给 curl 时中文正文会让服务端报 `VALIDATION_FAILED`。因此流程脚本正文改用 ASCII；**中文正文的契约由 `api-full-test.sh` 覆盖**（它能通过，说明服务端对中文的处理本身没问题，是脚本传输层的问题）。
3. 第 11 步的终止会话路径我写错了（401），但同一端点已被 API 全量测试覆盖，所以不影响结论；脚本里保留了这条提示，避免误读成"功能缺失"。
4. 两个脚本都已入库（`scripts/`）：`api-full-test.sh`（144 项）+ `exam-flow-test.sh`（24 项）。
